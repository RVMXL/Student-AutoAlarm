# 0.16.0 — стекло бесцветное, ползунки работают по всему диапазону

Главное: правки обратной связи к стеклу 0.15.0 — (1) ползунки ничего не
делали; (2) карточки при нормальной прозрачности всё равно наследовали цвет
светлой/тёмной темы. Причина первой — кроссфейд между двумя крайностями
(резкая копия ↔ предельный «цветной туман»), амплитуды искажения в пару
пикселей и отклик только после отпускания ползунка; причина второй —
подложка контраста цветом темы (0.10–0.48 альфы) поверх фрагмента. Стекло
теперь бесцветное, мáтовость ведёт по лестнице из пяти уровней размытия,
ползунки откликаются мгновенно, искажение усилено и преломляет по двум осям,
нижняя панель тоже стеклянная. versionCode 1600.

## Что изменилось

### Стекло (2.1 → 2.2)

- **Бесцветное стекло.** Подложка контраста цветом темы УБРАНА — именно
  она красила стекло тёплым белым (светлая тема) или тёмным (тёмная).
  Сквозь стекло виден только фон: резкий при мáтовости 0, размытый при 1;
  из «цвета» остались лишь объёмные кромки (фаска сверху/снизу).
- **Ползунок «Матовость» работает по всему диапазону.** Вместо кроссфейда
  двух крайностей — лестница из 5 уровней размытия: резкий → лёгкая дымка →
  средний блёр → сильный → предельная муть. Мáтовость выбирает пару
  соседних уровней и долю смешения — каждая ступень даёт заметный скачок
  мутности, ползунок «действует» при каждом движении.
- **Мгновенный отклик ползунков.** Перетаскивание меняет стекло сразу
  (значение пишется прямо в состояние стекла), сохранение — по окончании
  перетаскивания.
- **Искажение различимо глазом**: амплитуда 4.5% → 12% высоты фрагмента
  (AGSL, Android 13+), волна преломляет по двум осям («жидкое стекло»);
  полосный фолбэк Android 8–12 усилен так же (0.05 → 0.12 высоты).
- **Нижняя панель — тоже стекло.** Состояние стекла раньше не доходило до
  bottomBar (провайдер оборачивал только NavHost) — панель оставалась
  плотной поверх фона. Теперь провайдер вокруг всего Scaffold.
- Лестница уровней строится один раз на файл — ползунки не перезапускают
  декодирование; плотная заглушка до готовности фона сохранена (текст
  читаем, «отпечатков» с мусорной геометрией нет).

### Документация

- README приведён к факту 0.15.0: «сегодня» в календаре отмечается
  полоской НАД названием дня (не точкой-акцентом под числом); маркеры
  дней — серая «есть пары» и цветная «секции» с числом.

## Технические детали

- `GlassBackdropState` держит список из 5 уровней (`GlassMath.LEVEL_COUNT`):
  резкая копия ~1600px + четыре размытых из 720px-базы (÷2, ÷6, ÷14 ×2,
  ÷14 ×3 прохода downscale→upscale). У каждого уровня своя матрица
  BitmapShader (пропорции одинаковы — отображение визуально совпадает).
- `GlassMath.levelMix(matteness)` — чистая позиция на лестнице: (индекс
  нижнего уровня, доля смешения к следующему); покрыта тестами (границы,
  зажимы, монотонность позиции по всему ползунку).
- AGSL-шейдер: uA/uB (пара соседних уровней), uMix (доля), uAmp
  (амплитуда); смешение `mix(a, b, uMix)` ПОСЛЕ преломления сэмплинга —
  искажение видно и на резком, и на размытом уровне. Фолбэк < 33 — нижний
  уровень целиком + следующий с альфой доли; полосы сдвигают сэмплинг
  обеих матриц.
- Подложка (`scrimAlpha`) удалена вовсе: стекло = фрагмент + кромки.
  Плотная заглушка (`fallbackScrimAlpha`) осталась только на случай, когда
  уровни/геометрия ещё не готовы.
- Ключи настроек (`glass_blur`/`glass_distortion`) не менялись — миграций
  нет; SettingsScreen пишет в состояние стекла на каждом шаге
  перетаскивания и в DataStore по завершении.
- Тесты: GlassMathTest переписан (лестница, монотонность, усиленные
  амплитуды) — всего 71 юнит-тест.

## Известные ограничения

- На минимуме мáтовости стекло полностью прозрачно: читаемость текста
  поверх «пёстрой» картинки — на совести пользователя (так задумано:
  стекло бесцветное и не подкрашивает фон); ползунок мáтовости решает.
- Искажение через AGSL доступно с Android 13; на Android 8–12 —
  упрощённый полосный эффект (RuntimeShader существует только с 13).
- Память: 5 копий фона (~10 МБ на FullHD-картинке) — цена мгновенного
  отклика ползунков без пересборки блюра на каждое движение.

## Обновление

Установка поверх 0.15.0 (подпись не менялась — обновление встанет поверх).
Настройки стекла переносятся без изменений; если стекло раньше выглядело
«карточкой цвета темы» — теперь оно прозрачное и бесцветное, а степень
мутности настраивается ползунком по лестнице уровней.
