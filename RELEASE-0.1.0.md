# Student-AutoAlarm 0.1.0

Первая сборка: авто-будильник по расписанию КГЭУ. Приложение само ставит будильник
в **стоковые часы** перед первой парой — по данным официального API `kabinet.kgeu.ru`.

## Что нового

- **Мастер настройки** (5 шагов, ~1 минута): вуз → студент/преподаватель → поиск группы
  или ФИО преподавателя по официальному API → «за сколько обычно встаёшь до первой пары».
- **Режим «Стандарт»** — каждую ночь в 00:05 приложение перепроверяет расписание на завтра
  и переставляет будильник: первая пара минус ваше время на подъём.
- **Режим «На несколько дней вперёд»** — одноразовые будильники сразу на 3–14 дней
  (страховка от агрессивных планировщиков оболочек; чистить в часах вручную).
- **Исключения** — дисциплины, перед которыми будильник не ставится (переключаются
  прямо из расписания).
- **Свои занятия** — физкультура/секции: свой день недели или дата, время,
  отдельное смещение.
- **Большой тумблер** автовключения на главном экране; уведомление
  «Будильник поставлен на HH:MM (дисциплина, аудитория)».
- **Кастомизация**: тема системная/светлая/тёмная, Material You (Android 12+),
  6 палитр акцента, стиль расписания «Бумажный календарь», своя картинка на фон.
- **Помощник по выживанию**: подсказки автозапуска для Xiaomi/Huawei/Oppo/Samsung,
  отключение оптимизации батареи, разрешение точных будильников (Android 12+).
- Числитель/знаменатель не считаются приложением: сервер КГЭУ отдаёт конкретные даты.

## Установка

1. Скачайте `Student-AutoAlarm-0.1.0-android.apk` из ассетов ниже.
2. Разрешите установку из неизвестных источников для вашего проводника/браузера.
3. Требования: Android 8.0+ (API 26), стоковые часы с поддержкой `ACTION_SET_ALARM`,
   интернет для загрузки расписания.

## Обновление поверх (важно)

Все релизы проекта подписаны **одним и тем же стабильным ключом**, поэтому каждый новый
APK ставится поверх старого без удаления: настройки, исключения и кэш расписания
сохраняются. SHA-256 сертификата подписи:

`FD:29:47:48:43:08:64:89:7F:87:30:57:A7:2F:19:C1:E7:B2:D3:CB:B7:F4:CB:CF:2D:D4:95:F5:C5:95:F5:A0`

Если SHA-256 сертификата не совпал — это не официальный релиз.

## Приватность

Нет аналитики, рекламы и своих серверов: расписание запрашивается напрямую у КГЭУ,
всё остальное хранится только на устройстве.
