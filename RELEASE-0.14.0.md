# 0.14.0 — будильник снимается с заблокированного экрана, стекло по-новому, 5 тем

Главное: пять пожеланий из обратной связи — (1) звенящий будильник движка
«В приложении» теперь можно отключить прямо с заблокированного экрана (экран
сам загорается, кнопка «Отключить» — в уведомлении и на полноэкранном звонке);
(2) дни расписания помечаются маркерами; (3) кружки акцентов показывают
реальный цвет + палитра «своего цвета»; (4) стекло переработано — два ползунка
(матовость и искажение), размытие только за стеклом, фоновая картинка остаётся
резкой; (5) пять новых стилей расписания. versionCode 1400.

## 1. Что изменилось (было → стало)

| Ситуация | 0.13.0 | 0.14.0 |
|---|---|---|
| Звонок будильника «В приложении» при заблокированном экране | экран не просыпался, если оболочка игнорировала full-screen intent: будильник звенел «в темноту», снять можно было только из шторки после разблокировки | экран страховочно включается wake-lock'ом; уведомление полностью видно на локскрине с кнопкой «Отключить»; RingActivity с большой кнопкой поднимается поверх блокировки |
| FSI не выдан (Android 14+) | приложение молча уходило на фолбэк | в настройках будильника появляется честная подсказка «Будильник не включает экран» с переходом в системные настройки разрешения |
| Дни недели в расписании | видно только «сегодня» (точка-акцент) | серая точка — «в этот день есть пары»; цветная точка с числом — столько обозначенных (исключённых) секций; «сегодня» — по-прежнему акцентная точка, цвета маркеров другие |
| Кружки выбора акцента | всегда светлый вариант палитры — в тёмной теме цвет кружка ≠ фактический акцент | кружок = реальный акцент текущей темы (в тёмной — primaryDark) |
| Свой акцентный цвет | только 6 готовых палитр | 7-й кружок «Свой цвет» (радуга + пипетка) открывает палитру: квадрат насыщенность/яркость + ползунок тона + превью; тема строится из выбранного цвета |
| Стекло | размывалась ВСЯ фоновая картинка + один ползунок «интенсивность» | картинка всегда резкая; за каждой стеклянной поверхностью — её размытый и искажённый фрагмент фона; ползунки «Матовость» и «Искажение», видны только при включённом стекле; объёмные кромки в духе iOS |
| Стили расписания | «Стандарт» / «Бумажный календарь» | + «Мел и доска», «Неон», «Терминал», «Акварель», «Ретро-печать»; выбор — горизонтальная лента плиток-миниатюр |

## 2. Технические детали

**Отключение с локскрина:**
- `AlarmFireReceiver` перед показом уведомления включает экран wake-lock'ом
  `FULL_WAKE_LOCK | ACQUIRE_CAUSES_WAKEUP | ON_AFTER_RELEASE` (10 с) — это
  страховка для оболочек, игнорирующих full-screen intent; добавлено разрешение
  `WAKE_LOCK`. Дальше экран держит RingActivity (`FLAG_KEEP_SCREEN_ON`).
- Звонящее уведомление: `setVisibility(VISIBILITY_PUBLIC)` — уведомление
  с кнопкой «Отключить» не прячется приватностью локскрина.
- Существующий конвейер без изменений: FSI → RingActivity (showWhenLocked +
  turnScreenOn, manifest-атрибуты), фолбэк startActivity при отказанных
  уведомлениях/FSI (0.10.0, AL-10/AL-11).
- Подсказка FSI: на Android 14+ проверяется `canUseFullScreenIntent()`; если
  не выдано — строка в настройках будильника открывает
  `ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT` (с фолбэком на страницу приложения).

**Маркеры дней:**
- `domain/DayMarkers.countMarked()` — чистая функция: число РАЗЛИЧНЫХ дисциплин
  дня под активными исключениями (нормализация та же, что в isExceptional).
- Чип дня: маркеры рисуются под числом только у невыбранного дня; точка
  «сегодня» — акцентная (4dp), «есть пары» — нейтральная (inkSoft),
  «исключённые секции» — цвет стиля (mark) + числовая метка. У каждого скина
  маркер отличается от акцента (зафиксировано тестом).

**Акцент:**
- `customAccentPalette(argb)` — собирает полную AccentPalette из одного цвета
  в HSV: primary темнее базы на светлом / светлее на тёмном, контейнеры —
  светлые/тёмные тона того же тона, третичный — сдвиг тона +40°. Чистые
  `argbToHsv`/`hsvToArgb` (без android.graphics) — покрыты тестами.
- Палитра выбора: Canvas-квадрат S/V + радужный ползунок тона (тап и драг),
  превью, «Готово» применяет цвет и включает «Свой цвет»
  (`Settings.customAccentColor` + `accentIndex = CUSTOM_ACCENT_INDEX`).

**Стекло 2.0:**
- Фоновая картинка в `MainScaffold` больше не размывается глобально — раньше
  `Modifier.blur()` размывал весь рисунок, даже там, где перед ним нет стекла.
- `ui/theme/GlassBackdrop`: `GlassBackdropState` хранит размытый кэш фона
  (декод с прореживанием + боковое размытие downscale→upscale, перегенерация
  по квантованной матовости, шаг 0.05); `Modifier.glassSurface(shape)` рисует
  ПОД поверхностью её фрагмент фона (пересчёт координат как у
  ContentScale.Crop) с «линзовым» искажением: вертикальные полосы со
  синусоидальным сдвигом + зум; сверху — морозная заливка и объёмные кромки
  (светлая фаска сверху / тёмная снизу).
- Ползунки: «Матовость» (glassBlur: сила размытия кэша + плотность заливки),
  «Искажение» (glassDistortion: амплитуда волн и зум). Видны только при
  включённом стекле. Миграция: старое `glass_intensity` читается как начальная
  матовость и больше не пишется.
- Чистая математика в `GlassMath` (blurScale/frostAlpha/stripCount/
  stripShiftFraction/zoomFactor) — покрыта юнит-тестами.
- Стекло применино к карточкам главных экранов (Главная, Расписание, Настройки)
  и нижней панели навигации; диалоги остаются без фрагментов фона
  (полупрозрачная заливка, как раньше). Без фоновой картинки стекло, как и
  раньше, не включается (UI-20, контраст по WCAG).

**Стили расписания:**
- Булев флаг «paper» заменён на `CalendarSkin` (ui/theme/CalendarSkins.kt):
  фон/карточка/чернила/акцент/маркер/линии + флаги шрифта (антиква/моно) и
  неоновой обводки. Новый стиль = новый скин.
- «Мел и доска» (тёмно-зелёная доска, меловые чернила, серифы), «Неон» (чёрный
  фон, кислотный акцент, моно, светящаяся обводка карточек), «Терминал»
  (фосфорно-зелёный монохром, моно), «Акварель» (пастель), «Ретро-печать»
  (газетный крем, чёрные чернила, печатный красный акцент, серифы).
- Выбор стиля — лента плиток-миниатюр (мини-макет в цветах стиля + подпись).

## 3. Обновление

- Установить APK поверх предыдущей версии — данные (расписание, настройки,
  исключения, свои занятия) сохраняются; ключ подписи прежний.
- После обновления: старое значение «интенсивности стекла» становится начальной
  матовостью; «Искажение» по умолчанию 0.25.
- Скорый звонок для проверки: «Настройки → Будильник → Проверить будильник» —
  через 2 минуты; заблокируйте экран и убедитесь, что он сам загорается, а
  «Отключить» доступно без разблокировки.

## 4. Известные ограничения

- Включение экрана wake-lock'ом — страховка: некоторые оболочки дополнительно
  гасят экран на заблокированном устройстве; в этом случае поможет подсказка
  FSI в настройках (выдать разрешение полноэкранного звонка).
- Диалоги (выбор цвета, времени, офсетов) не рисуют фрагмент фона под собой —
  только полупрозрачная заливка (техническое ограничение: окно диалога не знает
  геометрию фона главного окна).
- «Искажение» — приближение настоящей рефракции полосами со сдвигом и зумом;
  это не физически точная имитация линзы, но даёт читаемый «живой» эффект даже
  на слабых устройствах (без RenderEffect, работает на всех API от 26).
