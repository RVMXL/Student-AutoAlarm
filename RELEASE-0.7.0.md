# 0.7.0 — будильник, который слушается тумблера

Три бага из жизни: тумблер ставил будильник не на тот день, выключение не снимало
будильник, а исключение по типу пары ловило все типы разом. Все три закрыты, плюс
новый движок — **будильник в самом приложении**, на который оболочка телефона не может
повлиять.

## 1. Будильник ставился на день без пар (раз через раз)

**Что было:** включаешь авто-будильник — иногда он встаёт на завтра, хотя завтра пар
нет (звонит во время пары, которая на самом деле послезавтра). «Раз через раз».

**Почему:** постановка опиралась на кэш расписания. КГЭУ часто публикует замены **после**
последней синхронизации: в кэше пара на завтра ещё есть, в реальности — уже отменили.
Тумблер честно ставил будильник по устаревшим данным.

**Что сделано:**

- Включение тумблера, смена режима и онбординг перед постановкой **тихо подтягивают
  свежие недели** (сейчас и через 7 дней — вместе покрывают двухнедельный горизонт;
  бюджет 12 секунд, при сбое сети постановка идёт по кэшу, ничего не блокируется).
- **Ночная сверка (00:05, «Стандарт»)**: план на завтра сверяется с будильником,
  поставленным в прошлый раз:
  - пары отменили → фантомный будильник **снимается**;
  - замена сдвинула время подъёма → старый снимается, ставится новый;
  - всё совпало → новый **не** создаётся (`SET_ALARM` каждый раз добавляет новый
    будильник — раньше это могло плодить дубликаты).

## 2. Выключение тумблера не снимало будильник

**Что было:** часы ColorOS/Realme UI принимают `SET_ALARM` (особенно с «Показывать часы»),
но молча игнорируют `DISMISS_ALARM` — приложение не может снять будильник в чужом
приложении никаким документированным способом. Честный фолбэк «открыть список будильников»
остался, но требовал ручного труда.

**Что сделано — движок «В приложении»:** настройка **«Где звонит будильник»**:

| | «В часах» (по умолчанию) | «В приложении» |
|---|---|---|
| Сигнал | Привычные стоковые часы | Собственный полноэкранный звонок приложения |
| Включение тумблера | `ACTION_SET_ALARM` (как раньше) | `AlarmManager.setAlarmClock` — точен даже в Doze, системный значок будильника |
| Выключение тумблера | `DISMISS_ALARM` по меткам + фолбэк | **Гарантированно** — отмена своего `PendingIntent` |
| Звонок | Часы телефона | Полноэкранный звонок поверх экрана блокировки (`showWhenLocked` + `turnScreenOn`), крупная кнопка «Отключить», действие в уведомлении |
| Звук/вибрация | Настройки часов | Системный звук будильника + вибрация, foreground-сервис, автоглушение через 10 минут («Будильник пропущен») |
| После звонка | — | В «Стандарте» следующий будильник ставится сразу |
| После перезагрузки | Часы помнят сами | `BootReceiver` восстанавливает будильник немедленно |

Тумблер, режимы, исключения, «Проверить будильник», смена цели — работают одинаково в
обоих движках; смена цели делает «чистый лист» (снимает оба, ставит активным).
**Если ваши часы капризничают (Realme UI, ColorOS, MIUI) — выберите «В приложении».**

## 3. Исключения: точное название, тип — в приставке

**Что было:** исключение «л. материаловедение» гасило будильник перед **всеми** парами
материаловедения — и лекцией, и практикой, и лабораторной (нормализация срезала
приставку типа), а иконка в расписании «красила» всю дисциплину. Отдельные чипы типов
ничего не меняли.

**Что стало:** правило сопоставляется **точным полным названием — вместе с приставкой**:

- «л. материаловедение» → не звонить перед лекцией;
- «пр. материаловедение» → практику не трогает, звоним;
- «лаб. …» → только лабораторная.

Тип уже написан в названии пары — отдельные тумблеры типов убраны за ненадобностью.
Иконка в расписании теперь работает с парой точно: тап по лекции гасит только лекцию.
Автодополнение при добавлении предлагает полные названия из вашего расписания.

## Мелочи

- Включение тумблера теперь честно отчитывается снекбаром и для движка «В приложении».
- Часы-настройка «Показывать часы при постановке» видна только для движка «В часах».
- +10 строк перевода на все 15 языков (251 → 261 ключ).

## Обновление

Ставится **поверх** 0.2.0–0.6.0: подпись стабильна, настройки/исключения/кэш сохраняются.
Новых разрешений два смысловых: вибрация и полноэкранное уведомление звонка
(полный список — в README).
