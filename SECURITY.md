# Политика безопасности

## Поддерживаемые версии

Обновления безопасности получает только актуальная линейка версий:

| Версия | Поддержка |
| ------ | --------- |
| 0.6.x  | ✅ |
| 0.5.x  | ❌ |
| 0.4.x и старее | ❌ |

Рекомендуется всегда использовать последнюю версию из
[Releases](https://github.com/RVMXL/Student-AutoAlarm/releases).
Приложение подписано одним стабильным ключом, поэтому обновление ставится
поверх старой установки без удаления настроек и расписания.

## Как сообщить об уязвимости

Пожалуйста, **не публикуйте** подробности уязвимости в открытых Issues.

Используйте приватные отчёты GitHub: вкладка **Security** → **Report a
vulnerability** этого репозитория. Отчёт видит только владелец репозитория.

В отчёте укажите:

- версию приложения (Настройки → О приложении) и модель устройства / версию Android;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- оценку серьёзности, если она вам известна.

Ответ — в течение **7 дней**. После подтверждения исправление попадает в
следующий релиз; об обнаружившей уязвимости стороне можно упомянуть в заметках
релиза (по желанию).

## Что не считается уязвимостью

- Энергосберегающие оболочки (ColorOS, Realme UI, MIUI и т.п.), блокирующие
  интенты будильника или убивающие фоновую работу, — это особенность прошивки.
  Рекомендации по настройке есть в README и в заметках релизов.
- Системные разрешения, отозванные пользователем вручную (уведомления,
  точные будильники, автозапуск и т.д.).
- Устройства с root и подделанные APK. Ставьте приложение только из
  официального Release: подпись стабильна, её SHA-256 зафиксирован в заметках
  каждого релиза и в workflow (пин ключа).

## Поверхность атаки (коротко)

- Своих серверов, аналитики и рекламы нет: расписание запрашивается напрямую
  у сервера КГЭУ по HTTPS.
- Настройки и расписание хранятся только на устройстве (Room + DataStore) и
  никуда не отправляются.
- Ключ подписи релиза хранится только в Secrets GitHub Actions и никогда не
  попадает в репозиторий.
