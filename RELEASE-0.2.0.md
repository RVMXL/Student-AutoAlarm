# Student-AutoAlarm 0.2.0

Обновление по отчётам с реального железа (Realme GT Neo 5 SE): фикс контраста,
надёжный фолбэк для оболочек, блокирующих будильники, и новое оформление.

Ставится **поверх 0.1.0 без удаления** — настройки сохраняются (подпись та же).

## Исправлено

- **Чёрные заголовки на тёмном фоне** — «Кто вы?», «Автобудильник КГЭУ» и другие
  надписи мастера настройки теперь окрашиваются из темы (тёмная тема — светлый текст).

## Новое

- **Напоминание о будильнике** (настройки → «Напоминание о будильнике»):
  - если часы телефона не принимают команды приложения — встречается на Realme UI
    китайского рынка, Huawei, Xiaomi — включите тумблер и выберите время
    (по умолчанию 21:00);
  - каждый день в выбранное время приходит уведомление: «Завтра, 14 октября:
    пара в 08:00 — Наноматериалы и нанотехнологии, ауд. Б308. Не забудьте
    поставить будильник»;
  - напоминание не приходит в дни, когда пар нет; работает независимо от часов.
- Будильники в стоковые часы теперь **ставятся даже при неопределённом ответе**
  системы (resolveActivity): если часы всё же откажут — уведомление подскажет
  включить напоминание.
- **Автодополнение исключений**: в поле названия дисциплины вводите буквы —
  подсказки из вашего реального расписания (например «ма» → «материаловедение»).
- **Настенный календарь** (стиль «Бумажный календарь» перерисован): лист с
  кольцами-пружиной и шапкой месяца, расписание — на самом листе, ваш фон
  виден вокруг.
- **Эффект стекла** (настройки → «Оформление»): тумблер + ползунок интенсивности.
  Карточки полупрозрачные, фоновая картинка размывается (размытие — Android 12+,
  на более старых версиях работает прозрачность).

## Установка / обновление

1. Скачайте `Student-AutoAlarm-0.2.0-android.apk` из ассетов ниже.
2. Установите **поверх** версии 0.1.0 — перенастройка не требуется.
3. После установки: Настройки → «Напоминание о будильнике» — включить (рекомендуется
   на Realme/Huawei/Xiaomi).

## Обновление поверх (важно)

поверх старого без удаления данных. SHA-256 сертификата подписи:
