# Student-AutoAlarm 0.3.0

Разбор мнения Gemini по проблеме ColorOS + собственная диагностика: найден и устранён
**корень** «будильники не ставятся вообще» на Realme GT Neo 5 SE (Realme UI китайского
рынка) — и ещё два барьера вдобавок.

Ставится **поверх 0.2.0/0.1.0 без удаления** — настройки сохраняются (подпись та же).

## Исправлено — почему будильники не ставились

Три независимых барьера, устранены все:

1. **Отсутствовало разрешение `com.android.alarm.permission.SET_ALARM`.**
   Без него стоковые часы молча игнорируют команду постановки. Ни одно пользовательское
   разрешение этого не чинит — только манифест приложения.
2. **Интент был неявным** («кричит в пустоту — кто-нибудь поставь»). ColorOS такие
   молча глушит. Теперь приложение **само находит** установленный пакет часов
   (com.oplus.alarmclock / com.coloros.alarmclock / Samsung / Xiaomi / Huawei /
   Pixel / Tecno-Infinix) и адресует команду напрямую — явный интент оболочка
   обязана доставить по адресу.
3. **Фоновая постановка без показа экрана** (`EXTRA_SKIP_UI=true`) блокируется ColorOS
   как «подозрительная». В настройках появился тумблер **«Показывать часы при
   постановке»**: часы открываются с уже заполненным будильником — подтвердите
   кнопкой «Сохранить». Один тап в день, зато гарантированно работает.

Если будильник не прошёл даже после этого — приложение уведомит и подскажет включить
«Напоминание о будильнике» (оно не зависит от часов вовсе).

## Подъём под каждую пару

Раньше будильник считался так: «первая пара минус один и тот же запас на сборы».
Но так живут только люди с железным режимом. Теперь у каждого времени первой пары
можно задать **свой запас**:

- пара в **08:00** → подъём попозже (дома не завтракаете);
- пара в **09:40** / **11:20** → подъём пораньше, чтобы успеть позавтракать.

В настройках будильника появилась секция **«Подъём под каждую пару»**: приложение
само собирает времена первых пар из вашего расписания, для каждого — своя кнопка
«Изменить» (слайдер, пресеты и живой пример «будильник прозвонит в …»). Пары без
своего значения используют общий подъём, «Сбросить» возвращает всё как было.

## Одноразовые будильники: отключение и уборка

Коротко про возможности Android: **удалять будильники из стоковых часов стороннее
приложение не может** — такого API не существует (в контракте AlarmClock есть только
постановка, показ списка, отключение и повтор). Что сделано в рамках разрешённого:

- кнопка **«Список будильников»** (раздел «Будильник») — открывает будильники телефона,
  где лишние удаляются вручную;
- кнопка **«Отключить будильники приложения»** (режим «на несколько дней вперёд») —
  часы сами показывают будильники с меткой «Авто:» и позволяют их отключить;
- приятный факт из контракта: одноразовые будильники, поставленные без показа экрана,
  часы **удаляют сами после звонка** — хвост из прошлых дней не копится.

## Рекомендуемые настройки на Realme/Oppo (ColorOS)

Настройки → Приложения → Автобудильник КГЭУ:
- **Автозапуск** — включить;
- **Отображение поверх других окон** — разрешить;
- **Батарея** — «Без ограничений» (не «умный режим»).

## Приватность

Нет аналитики, рекламы и своих серверов: расписание запрашивается напрямую у КГЭУ,
всё остальное хранится только на устройстве.
