# Student-AutoAlarm

Student-AutoAlarm: Android-приложение (Kotlin, Jetpack Compose), которое по расписанию
КГЭУ автоматически ставит будильник перед первой парой — **в стоковое приложение часов**
или, по выбору, **собственным будильником приложения** (полноэкранный звонок с кнопкой
«Отключить»). Сейчас расписание берётся из официального публичного API личного кабинета
[`kabinet.kgeu.ru`](https://kabinet.kgeu.ru/WebApp/#/Rasp/List)
(архитектура допускает добавление других вузов — слой провайдера расписания изолирован).

Приложение работает по единой логике **«одна ночь вперёд»** (0.8.0): включение тумблера
проверяет сегодня/завтра и сразу ставит будильник на ближайшее пробуждение (со свежим
расписанием — замены!), а каждую ночь в 00:05 (и страховкой в 06:00) проверщик смотрит,
есть ли пары в наступивший день, и ставит будильник на ближайшее время — или не ставит,
если пар нет. Никаких будильников «на день недели», которые потом приходится выключать
руками; замены и отмены пар переставляют/снимают будильник сами. Вычитание выбранного
вами времени на подъём и сборы, «под каждую пару» — у каждой пары может быть своё время
подъёма. Числитель/знаменатель разворачивает в конкретные даты сам сервер КГЭУ,
приложение работает только с фактическими датами.

Интерфейс переведён на **15 языков**: русский, татарский, английский, арабский (с RTL),
узбекский, казахский, кыргызский, таджикский, туркменский, чувашский, французский,
испанский, турецкий, китайский, башкирский. Язык выбирается на первом шаге мастера
настройки и меняется в «Настройки → Оформление → Язык».

## Как это работает

| Этап | Что происходит |
|---|---|
| Первая настройка | Язык интерфейса (15 языков, включая «язык системы») → вуз → роль (студент/преподаватель) → поиск группы или ФИО по API → «за сколько обычно встаёшь до первой пары» |
| Включение тумблера / мастер настройки / смена цели будильника | Будильник ставится **сразу** на ближайшее предстоящее пробуждение в пределах **сегодня и завтра** (логика 0.8.0): сначала тихо подтягивается свежее расписание (неделя сейчас + через 7 дней — замены нередко публикуют ПОСЛЕ последней синхронизации), затем — сегодня, если время подъёма ещё не прошло, иначе завтра. Дальше завтра не ставится ничего — за следующие дни отвечает ночная сверка. **Выключение тумблера снимает будильники приложения** (гарантированно отменяет собственный будильник движка «В приложении»; в часах снимает последний разовый и, для очистки наследия старых версий, «Авто: Пн…Вс» по точным меткам) и сбрасывает внутренние маркеры — включённый заново тумблер ставит будильник заново, даже если старый вы уже удалили в часах вручную |
| Ночь (00:05) и утро (06:00) | Точная сверка приложения: запрос свежего расписания (сегодня + следующая неделя, ~15 КБ), затем ночная сверка с ближайшим ПРЕДСТОЯЩИМ пробуждением в пределах сегодня+завтра: есть пара сегодня — будильник ставится на ближайшее время; пар нет — фантомный снимается; замена сдвинула время — старый снимается, ставится новый; совпал — не дублируется. Тик 06:00 — страховка: если 00:05 пропущено (телефон был выключен, оболочка придавила точный будильник), утренний тик всё ещё успевает поставить будильник на первую пару дня. В движке «В приложении» слот перезаписывается свежим планом — самолечение по построению; в движке «в часах» ставятся только РАЗОВЫЕ будильники — повторов «на день недели» больше нет |
| После перезагрузки | `BootReceiver` восстанавливает обе ночные сверки и немедленно восстанавливает ближайший будильник: в движке «В приложении» — перепоставляет безусловно (системный `AlarmManager` перезагрузку не переживает, а старый маркер дедупликации больше не «подтверждает» мёртвый слот — фикс 0.9.0); в движке «в часах» — сверка ставит разовый будильник на сегодняшнюю первую пару, если телефон был выключен всю ночь и оба тика пропущены (фикс 0.9.0). Резервный `WorkManager` синкает расписание каждые 12 часов и тоже сверяет будильник |
| В течение дня | Расписание можно перепроверить в любой момент (кнопка обновления); кнопки «Список будильников» и «Отключить будильники приложения» — управление тем, что уже стоит в часах |

Важно: с 0.7.1 будильник по умолчанию звонит **в приложении** (полный контроль тумблера,
точная дата, гарантированное снятие) — `SET_ALARM` стоковых часов не умеет «на дату»,
а `DISMISS_ALARM` на части оболочек (ColorOS/Realme UI) молча игнорируется. Если хотите
сигнал в привычных часах — переключите **«Где звонит будильник → В часах»**: с 0.8.0 там
ставятся только разовые будильники в пределах сегодня/завтра (дата соблюдается по
построению: ночной тик 00:05 ставит будильник в сам день пары), но снятие по-прежнему
зависит от оболочки.

## Ключевые возможности

- **Единая логика «одна ночь вперёд» (0.8.0)** — будильник ставится максимум на завтра: включение тумблера проверяет сегодня/завтра, ночная сверка 00:05 (+страховка 06:00) каждый день ставит будильник на ближайшую пару наступившего дня или снимает фантом, если пар нет. Режим «на несколько дней вперёд» (партия недельных будильников «Авто: Пн…Вс») удалён — при смене расписания такие будильники приходилось выключать руками; наследие старых установок снимается одноразовой миграцией при первом запуске 0.8.0. Под каждую пару — своё время подъёма (настраивается отдельно в диалоге с пресетами), у пар без своего значения — общий подъём.
- **Будильник в приложении (0.7.0; с 0.7.1 — по умолчанию)** — настройка **«Где звонит будильник»**: «В приложении» — собственный точный будильник (`AlarmManager.setAlarmClock`): полноэкранный звонок поверх экрана блокировки с кнопкой «Отключить», системный значок будильника, автоглушение через 10 минут с пометкой «пропущен» — либо «В часах» (через `ACTION_SET_ALARM`, только разовые будильники сегодня/завтра). Тумблер, исключения и снятие работают **гарантированно** в движке приложения — оболочка не может молча блокировать собственный будильник приложения.
- **Занятия-исключения (0.7.0: точные)** — перед парами, чьё **полное название совпало точно**, будильник не ставится: тип уже написан в названии пары приставкой, и правило учитывает его: «л. материаловедение» гасит только лекцию, «пр. материаловедение» — только практику, «лаб. …» — только лабораторную. Никаких отдельных «тумблеров типов» — они не нужны. Переключаются прямо из расписания иконкой (иконка больше не «красит» все типы дисциплины разом); при добавлении — автодополнение по полным названиям из вашего реального расписания («мате» → «л. материаловедение», «пр. материаловедение»…).
- **Свои занятия** — например, физкультура или секция, которых нет в расписании: свой день недели (или дата), время и **отдельное** смещение будильника.
- **Большой тумблер** авто-будильника на главном экране — отключение в одно касание. Выключение **снимает будильники приложения** (гарантированно — в движке «В приложении»; по меткам с честным фолбэком — в часах) и отчитывается снекбаром. Включение подтягивает свежее расписание и ставит будильник заново: «удалил будильник в часах → включил-выключил тумблер → будильник вернулся», ждать полуночи не нужно.
- **Управление будильниками в часах** — кнопка «Список будильников» открывает будильники телефона; «Отключить будильники приложения» через официальный канал `DISMISS_ALARM` отключает и партию «Авто: Пн…Вс», и последний разовый будильник (по точным меткам «Авто: …»); если оболочка команду не принимает (часть Realme UI/ColorOS) — приложение сообщает об ограничении и само открывает список будильников для ручного отключения.
- **Уведомления** «Будильник поставлен на 07:00 (пр Атомные электрические станции, ауд. А413)».
- **Кастомизация**: тема (системная/светлая/тёмная), Material You (динамический цвет Android 12+), 6 палитр акцента (без «дефолтного синего»), стиль расписания **«Бумажный календарь»**, своя картинка на фон с регулировкой прозрачности; светлая и тёмная темы всегда следуют теме приложения — окно и поверхности окрашиваются согласованно, без «серой каши» при тёмной системе. Сегментные переключатели темы/стиля держат одинаковую высоту на любом языке — длинные слова не «раздувают» пилюлю (переполнение — многоточием).
- **15 языков интерфейса** (ru, tt, en, ar, uz, kk, ky, tg, tk, cv, fr, es, tr, zh, ba): переводятся все экраны, уведомления, дни недели и даты; названия языков в списке — родным именем и на текущем языке («English / Английский»); сверху — русский, татарский и английский.
- **Перепроверка расписания**: данные не считаются «вечными» — кэш старше трёх суток помечается предупреждением, замены пар помечаются бейджем «замена», а каждое обновление подтверждается снекбаром: успех с числом пар или причина ошибки (нет связи / сеть недоступна / сбой сервера).
- **Напоминание о будильнике** — фолбэк для оболочек, блокирующих установку будильников (Realme UI китайского рынка, Huawei и др.): каждый день в выбранное время приходит своё уведомление «завтра пара во столько — не забудьте поставить будильник».
- **Совместимость с ColorOS/Realme UI** — приложение само находит установленный пакет часов (Oppo/OnePlus/Realme, Samsung, Xiaomi/Huawei, Pixel, Tecno/Infinix) и адресует команду напрямую; для самых агрессивных оболочек есть тумблер «Показывать часы при постановке» — часы открываются с готовым будильником, подтверждение одним тапом.
- **Ориентация в календаре**: текущая неделя выделена цветом акцента с бейджем «эта неделя», сегодняшний день — жирным с точкой-акцентом под числом, в шапке кнопка возврата к сегодняшней неделе (подсвечена, пока вы «уехали»).
- **Эффект стекла** — карточки полупрозрачные, фоновая картинка размывается; интенсивность — ползунком. Стекло работает только вместе с фоновой картинкой — без неё карточки остаются плотными и контрастными.
- **Настенный календарь** — стиль «Бумажный календарь»: нарисованный лист с кольцами и шапкой месяца, расписание внутри, ваш фон вокруг.

## Установка и запуск

### Android (ARM64 / ARM32 / x86_64)

1. Скачайте APK из раздела [Releases](https://github.com/rvmxl/Student-AutoAlarm/releases).
2. Откройте файл и разрешите установку из неизвестных источников для вашего проводника/браузера.
3. Запустите «Автобудильник КГЭУ» и пройдите мастер настройки (6 шагов, ~1 минута: язык → роль → группа → подъём → финиш).

**Требования:** Android 8.0+ (API 26); установленное стоковое приложение часов, принимающее
`ACTION_SET_ALARM` (есть на всех стандартных оболочках); интернет для загрузки расписания.

### Обновление

- Установите новый APK **поверх старого** — настройки, исключения и кэш расписания сохраняются (DataStore/Room).
- Обновления поверх работают потому, что все релизы подписываются **одним и тем же стабильным ключом**
  (хранится в Secrets CI, в git не попадает; SHA-256 ключа зафиксирован пином в workflow —
  подмена секрета ломает сборку, а не молча подписывает APK чужим ключом).
- SHA-256 сертификата подписи (сверяйте после обновлений):
  `FD:29:47:48:43:08:64:89:7F:87:30:57:A7:2F:19:C1:E7:B2:D3:CB:B7:F4:CB:CF:2D:D4:95:F5:C5:95:F5:A0`
- После обновления в 00:05 приложение само продолжит работу; перенастройка не требуется.

### Первый запуск — чек-лист выживания

1. Мастер настройки: язык интерфейса → группа/преподаватель → время на подъём → «Готово».
2. Разрешите уведомления (Android 13+ запросит сам).
3. Настройки → **«Система»**: отключите оптимизацию батареи и добавьте приложение в автозапуск (инструкция под вашего производителя — Xiaomi/Huawei/Oppo/Samsung и т. д.).
4. Нажмите **«Проверить будильник»** — в часах появится тестовый будильник через 2 минуты.
5. **Будильники не ставятся вообще** (бывает на Realme/Huawei/Xiaomi, особенно китайских прошивках)?
   Включите **Настройки → «Напоминание о будильнике»** и выберите время — приложение будет
   присылать своё уведомление с первой парой на завтра.
6. **Сам удалил будильник в часах / выключил тумблер — как вернуть будильник?** Просто
   включите тумблер авто-будильника заново — будильник встанет на ближайшее
   пробуждение (сегодня/завтра) немедленно.
7. **Часы игнорируют команды приложения** (постановка только вручную, снятие не работает —
   часть Realme UI/ColorOS/MIUI)? С 0.7.1 движок «В приложении» включён по умолчанию —
   приложение звонит само, полный контроль тумблера без ограничений оболочки
   (вернуть часы можно в Настройки → **«Где звонит будильник» → «В часах»**).

## Приватность и разрешения

Приложение не имеет аналитики, рекламы и серверов: всё хранится только в приватной папке
приложения. Минимум разрешений:

| Разрешение | Зачем |
|---|---|
| `INTERNET` | Загрузка расписания с `kabinet.kgeu.ru` |
| `SET_ALARM` | Постановка разового будильника в стоковые часы (движок «В часах»): `ACTION_SET_ALARM`/`DISMISS_ALARM`/`SHOW_ALARMS` |
| `RECEIVE_BOOT_COMPLETED` | Восстановить ночной планировщик и ближайший будильник после перезагрузки |
| `POST_NOTIFICATIONS` | Уведомления «будильник поставлен» (Android 13+) |
| `SCHEDULE_EXACT_ALARM` (Android 12–12L) + `USE_EXACT_ALARM` (Android 13+) | Ночная сверка срабатывает в 00:05 и 06:00, а не «примерно»; собственному звонку (`setAlarmClock`) разрешение не требуется |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Кнопка «Исправить» в настройках (не отправляет ничего) |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_DATA_SYNC` | Фоновая синхронизация расписания (WorkManager, expedited-fallback на Android < 12) |
| `VIBRATE` + `USE_FULL_SCREEN_INTENT` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | Звонок движка «В приложении»: вибрация, полноэкранное уведомление поверх экрана блокировки, фоновый сервис звонка |

## Структура репозитория

| Путь | Назначение |
|---|---|
| `app/src/main/java/ru/uniautoalarm/kgeu/data/model/` | Доменные модели (Lesson, Settings, AlarmPlan…) |
| `…/data/remote/` | API КГЭУ: OkHttp + kotlinx.serialization (DTO с русскими полями сервера) |
| `…/data/db/` | Room: кэш расписания, исключения, свои занятия |
| `…/data/repository/` | SettingsRepository (DataStore), ScheduleRepository (сеть+кэш) |
| `…/domain/` | AlarmPlanner — расчёт времени пробуждения |
| `…/alarm/` | Движки будильника: StockAlarmSetter (`ACTION_SET_ALARM` в часы), InAppAlarmScheduler + AlarmFireReceiver + AlarmRingingService (собственный звонок), AlarmGateway (маршрутизация по цели), ночная сверка, BootReceiver, уведомления |
| `…/work/` | WorkManager: периодический синк расписания |
| `…/ui/` | Compose: мастер настройки, главный экран, расписание, настройки, темы |
| `gradle/libs.versions.toml` | Version catalog (AGP 8.7.3, Kotlin 2.0.21, Compose BOM 2024.12.01) |

## Сборка из исходников

```bash
# 1. JDK 17+, Android SDK (platform 35, build-tools 35)
git clone https://github.com/rvmxl/Student-AutoAlarm.git
cd Student-AutoAlarm

# 2. local.properties со путём к SDK (или переменная ANDROID_HOME)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 3. Отладочная сборка APK
./gradlew :app:assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk

# 4. Юнит-тесты (31: AlarmPlanner, правила доставки, парсер API, паритет 15 локалей)
./gradlew :app:testDebugUnitTest

# 5. Релизная сборка — ТОЛЬКО со стабильным ключом подписи (обновления поверх):
#    env-переменные KEYSTORE_FILE, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
#    Ключа нет → сборка упадёт ЯВНО (автогенерация нового ключа запрещена:
#    чужой/новый ключ ломает установку обновлений поверх старых версий).
#    В CI ключ берётся из Secrets (см. .github/workflows/release.yml).
./gradlew :app:assembleRelease
```
