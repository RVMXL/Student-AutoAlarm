# UniAutoAlarm-KGEU

UniAutoAlarm-KGEU: Android-приложение (Kotlin, Jetpack Compose), которое по расписанию
КГЭУ автоматически ставит будильник в **стоковое приложение часов** перед первой парой.
Суффикс `-KGEU` — Казанский государственный энергетический университет: сейчас расписание
берётся из официального публичного API личного кабинета [`kabinet.kgeu.ru`](https://kabinet.kgeu.ru/WebApp/#/Rasp/List)
(архитектура допускает добавление других вузов — слой провайдера расписания изолирован).

Приложение каждый ночью перепроверяет расписание, вычисляет время первой пары **завтрашнего**
дня, вычитает выбранное вами время на подъём и сборы — и переставляет будильник в штатных
часах телефона. Ничего никуда вручную перекладывать не нужно, пары «сами не повторяются»:
числитель/знаменатель разворачивает в конкретные даты сам сервер КГЭУ, приложение работает
только с фактическими датами.

## Как это работает

| Этап | Что происходит |
|---|---|
| Первая настройка | Вуз → роль (студент/преподаватель) → поиск группы или ФИО по API → «за сколько обычно встаёшь до первой пары» |
| Ночь (00:05) | Точный будильник приложения: запрос расписания на завтра (`/api/Rasp?id…&sdate=завтра`, ~15 КБ), расчёт будильника, постановка в стоковые часы через `ACTION_SET_ALARM` (без открытия UI) |
| После перезагрузки | `BootReceiver` восстанавливает ночной планировщик; резервный `WorkManager` синкает расписание каждые 12 часов |
| В течение дня | Расписание можно перепроверить в любой момент (кнопка обновления); режим «на неделю вперёд» ставит партию одноразовых будильников |

Важно: приложение **не дублирует** будильник своими средствами — сигнал звенит там, где вы
привыкли, в стоковых часах, со всеми вашими настройками звука/вибрации.

## Ключевые возможности

- **Режим «Стандарт»** — каждую ночь будильник на завтра по первой паре; создаётся мало будильников, каждый активен ровно когда нужно. Рекомендуется добавить приложение в автозапуск и снять оптимизацию батареи (помощник внутри).
- **Режим «На несколько дней вперёд»** — одноразовые будильники сразу на 3–14 дней: страховка от агрессивных планировщиков Android-оболочек, которые убивают фоновые процессы. Минус: такие будильники в часах не удаляются автоматически и накапливаются — чистить вручную.
- **Занятия-исключения** — перед выбранными дисциплинами будильник не ставится (вы на них не ходите). Переключаются прямо из расписания иконкой.
- **Свои занятия** — например, физкультура или секция, которых нет в расписании: свой день недели (или дата), время и **отдельное** смещение будильника.
- **Большой тумблер** авто-будильника на главном экране — отключение в одно касание.
- **Уведомления** «Будильник поставлен на 07:00 (пр Атомные электрические станции, ауд. А413)».
- **Кастомизация**: тема (системная/светлая/тёмная), Material You (динамический цвет Android 12+), 6 палитр акцента (без «дефолтного синего»), стиль расписания **«Бумажный календарь»**, своя картинка на фон с регулировкой прозрачности.
- **Перепроверка расписания**: данные не считаются «вечными» — кэш старше трёх суток помечается предупреждением, замены пар помечаются бейджем «замена».

## Установка и запуск

### Android (ARM64 / ARM32 / x86_64)

1. Скачайте APK из раздела [Releases](https://github.com/rvmxl/UniAutoAlarm-KGEU/releases) (на момент v0.1.0 релизов ещё нет — соберите из исходников, см. ниже).
2. Откройте файл и разрешите установку из неизвестных источников для вашего проводника/браузера.
3. Запустите «Автобудильник КГЭУ» и пройдите мастер настройки (5 шагов, ~1 минута).

**Требования:** Android 8.0+ (API 26); установленное стоковое приложение часов, принимающее
`ACTION_SET_ALARM` (есть на всех стандартных оболочках); интернет для загрузки расписания.

### Обновление

- Установите новый APK поверх старого — настройки, исключения и кэш расписания сохраняются (DataStore/Room).
- После обновления в 00:05 приложение само продолжит работу; перенастройка не требуется.

### Первый запуск — чек-лист выживания

1. Мастер настройки: группа/преподаватель → время на подъём → «Готово».
2. Разрешите уведомления (Android 13+ запросит сам).
3. Настройки → **«Система»**: отключите оптимизацию батареи и добавьте приложение в автозапуск (инструкция под вашего производителя — Xiaomi/Huawei/Oppo/Samsung и т. д.).
4. Нажмите **«Проверить будильник»** — в часах появится тестовый будильник через 2 минуты.

## Приватность и разрешения

Приложение не имеет аналитики, рекламы и серверов: всё хранится только в приватной папке
приложения. Минимум разрешений:

| Разрешение | Зачем |
|---|---|
| `INTERNET` | Загрузка расписания с `kabinet.kgeu.ru` |
| `RECEIVE_BOOT_COMPLETED` | Восстановить ночной планировщик после перезагрузки |
| `POST_NOTIFICATIONS` | Уведомления «будильник поставлен» (Android 13+) |
| `SCHEDULE_EXACT_ALARM` | Ночной планировщик срабатывает в 00:05, а не «примерно» |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Кнопка «Исправить» в настройках (не отправляет ничего) |

## Структура репозитория

| Путь | Назначение |
|---|---|
| `app/src/main/java/ru/uniautoalarm/kgeu/data/model/` | Доменные модели (Lesson, Settings, AlarmPlan…) |
| `…/data/remote/` | API КГЭУ: OkHttp + kotlinx.serialization (DTO с русскими полями сервера) |
| `…/data/db/` | Room: кэш расписания, исключения, свои занятия |
| `…/data/repository/` | SettingsRepository (DataStore), ScheduleRepository (сеть+кэш) |
| `…/domain/` | AlarmPlanner — расчёт времени пробуждения |
| `…/alarm/` | StockAlarmSetter (`ACTION_SET_ALARM`), ночной планировщик, BootReceiver, уведомления |
| `…/work/` | WorkManager: периодический синк расписания |
| `…/ui/` | Compose: мастер настройки, главный экран, расписание, настройки, темы |
| `gradle/libs.versions.toml` | Version catalog (AGP 8.7.3, Kotlin 2.0.21, Compose BOM 2024.12.01) |

## Сборка из исходников

```bash
# 1. JDK 17+, Android SDK (platform 35, build-tools 35)
git clone https://github.com/rvmxl/UniAutoAlarm-KGEU.git
cd UniAutoAlarm-KGEU

# 2. local.properties со путём к SDK (или переменная ANDROID_HOME)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 3. Отладочная сборка APK
./gradlew :app:assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk

# 4. Релизная сборка (без подписи; подписывайте своим ключом)
./gradlew :app:assembleRelease
```
